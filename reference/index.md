# Package index

## All functions

- [`affyToR()`](https://waldronlab.io/HGNChelper/reference/affyToR.md) :
  Title function to convert Affymetrix probeset identifiers to valid R
  names
- [`checkGeneSymbols()`](https://waldronlab.io/HGNChelper/reference/checkGeneSymbols.md)
  : Identify outdated or Excel-mogrified gene symbols
- [`findExcelGeneSymbols()`](https://waldronlab.io/HGNChelper/reference/findExcelGeneSymbols.md)
  : Title function to identify Excel-mogrified gene symbols
- [`getCurrentHumanMap()`](https://waldronlab.io/HGNChelper/reference/getCurrentMaps.md)
  [`getCurrentMouseMap()`](https://waldronlab.io/HGNChelper/reference/getCurrentMaps.md)
  : Get the current maps for correcting gene symbols
- [`hgnc.table`](https://waldronlab.io/HGNChelper/reference/hgnc.table.md)
  : All current and withdrawn HGNC gene symbols and Excel-mogrified
  symbols
- [`mouse.table`](https://waldronlab.io/HGNChelper/reference/mouse.table.md)
  : All current and withdrawn MGI mouse symbols and Excel-mogrified
  symbols
- [`rToAffy()`](https://waldronlab.io/HGNChelper/reference/rToAffy.md) :
  Title function to convert the output of affyToR back to the original
  Affymetrix probeset identifiers.
- [`rToSymbol()`](https://waldronlab.io/HGNChelper/reference/rToSymbol.md)
  : Title function to reverse the conversion made by symbolToR
- [`symbolToR()`](https://waldronlab.io/HGNChelper/reference/symbolToR.md)
  : Title function to \*reversibly\* convert HGNC gene symbols to valid
  R names.
